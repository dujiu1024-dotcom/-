# 语义需求分析、聚类、强度与趋势

## 处理链路

评论事实 → 时间窗口过滤 → LLM 语义识别 → 需求分类 → 语义向量（可选）→ 相似需求聚类 → 证据集合 → 强度评分 → 时间趋势。

## LLM 配置

在本机 `.env` 配置 OpenAI-compatible API：`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`，以及可选的 `LLM_EMBEDDING_MODEL`。

不配置 LLM 时系统可运行本地规则识别与字符 n-gram 相似度聚类；这是降级模式，不应描述为完整语义模型。

## 需求强度评分

满分 100，当前透明规则分：需求评论数量最多 35 分；跨平台覆盖与独立作者最多 20 分；点赞反馈最多 15 分；最近出现时间最多 15 分；模型置信度最多 15 分。

分数是研究排序指标，不代表市场规模或付费意愿。后续可通过人工标注样本校准。

## 趋势分析

支持小时 / 天聚合。趋势以完成分析的评论证据为基础，按需求簇统计新增评论数；需周期性运行分析任务才能形成连续历史趋势。历史数据不足时不生成虚假趋势线。
